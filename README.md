# 로그라이크 게임 프로젝트 (바이브 코딩 기말과제)

본 프로젝트는 AI 에이전트와 협업하여 개발된 로그라이크(Rogue-like) 던전 탐험 게임입니다.
**[게임알고리즘(3A)]** 및 **[게임최적화기법(2A)]** 기말과제 제출용 산출물 구조를 준수하고 있습니다.

## 📁 프로젝트 폴더 구조 (과제 필수 준수 구조)
- `project/src/`: 실제 실행 코드 및 메인 게임 루프 (`main.lua` 등)
- `project/tests/`: 핵심 비즈니스 로직 검증을 위한 커스텀 테스트 하네스
- `docs/`: 제출용 양과목 보고서 템플릿 및 AI 에이전트 환경 설정 자료
- `worklogs/`: AI와의 협업 및 에러 수정 과정(Troubleshooting)이 기록된 로그
- `run.bat`: 윈도우 환경용 게임 자동 실행 스크립트

## 🚀 설치 및 실행 방법
1. 저장소 최상단 경로에서 `run.bat` 스크립트를 실행합니다.
   - 내부적으로 `love-11.5-win64/lovec.exe project/src` 명령을 호출하여 게임을 구동합니다.
2. 콘솔에서 직접 구동할 경우, 해당 폴더 내의 lovec.exe를 이용해 `project/src` 경로를 지정하면 됩니다.

## 🧪 테스트(검증) 실행 방법
기능의 안정성 및 오류 검증을 위해 작성된 테스트 코드를 실행할 수 있습니다.
다음 명령어를 터미널(또는 CMD/PowerShell)에 입력하세요:
```bash
"love-11.5-win64/lovec.exe" "project/tests"
```
> 테스트 실행 시 콘솔 창을 통해 각 기능(예: 인벤토리 처리 로직)에 대한 `[PASS]` 또는 `[FAIL]` 검증 결과가 출력되고 시스템이 자동 종료됩니다.
