# 에이전트 환경 설계 및 설정 자료

## 1. 시스템 프롬프트 및 사용 도구
- **사용 도구**: Windsurf / AI 에이전트 코딩 어시스턴트
- **기본 환경 설정**: Lua 5.1, Love2D 11.5 환경에 맞춤

## 2. 규칙 파일 / 설정 파일 요약
*(루트 경로의 `AGENTS.md` 혹은 `.windsurfrules.md` 파일에 정의된 주요 지침)*
- 기본 언어는 Lua를 사용한다.
- 모듈은 작게 유지하고 암묵적 전역(Global) 선언을 피한다.
- Love2D 코드 구조에서 `update`와 `draw`의 책임을 명확히 분리한다.
- 수정 및 개발 시 변경 파일의 이유와 검증/실행 방법을 함께 기록한다.
