# 에이전트 환경 설계 및 설정 자료

## 1. 시스템 프롬프트 및 사용 도구
- **사용 도구**: Windsurf / AI 에이전트 코딩 어시스턴트
- **기본 환경 설정**: Lua 5.1, Love2D 11.5 환경에 맞춤

## 2. 규칙 파일 / 설정 파일 요약
*(루트 경로의 `AGENTS.md` 혹은 `.windsurfrules.md` 파일에 정의된 주요 지침)*
- 기본 언어는 Lua 5.1 (Love2D 11.5 호환)을 사용한다.
- 모듈은 작게 유지하고 암묵적 전역(Global, `_G`) 변수 선언을 절대 금지한다.
- 관심사 분리(SoC): `love.update`의 연산 로직과 `love.draw`의 화면 렌더링 책임을 철저히 분리한다.
- **의존성 주입(DI) 패턴**: 모듈 간의 전역 참조를 피하기 위해 `init(ctx)` 메서드를 통해 `map`, `player`, `enemies`, `addMessage` 등의 컨텍스트를 주입받아 사용한다.
- **테스트 주도 개발(TDD)**: 새로운 핵심 모듈(예: 길찾기, 인벤토리, 전투) 작성 시 반드시 `project/tests/` 내에 모듈을 검증하는 테스트 파일을 함께 작성한다. 테스트 파일은 `main.lua` 하네스에서 자동화되어 실행될 수 있도록 `M.run()` 패턴을 준수한다.
- **트러블슈팅 로깅**: 버그 픽스 및 구조 변경이 있을 경우 `worklogs/troubleshooting_log.md` 파일 하단에 1) 문제 원인, 2) 지시, 3) AI 해결 및 근거, 4) 검증 결과를 누적 기록한다.
